# App Player (Android TV)

Pendiente — se construye en la última fase del proyecto (Flutter).

Responsable de: mostrar el código de emparejamiento, conectarse por WebSocket
al backend (IP local configurable), descargar y cachear el contenido asignado,
reproducir la playlist en loop respetando duración y programación horaria, y
seguir funcionando con el último contenido cacheado si se pierde la conexión.

Ver el flujo de emparejamiento y los eventos de WebSocket en
[`../docs/DATA_MODEL.md`](../docs/DATA_MODEL.md) y
[`../backend/README.md`](../backend/README.md).
